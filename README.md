# Telegram Auto Bot

Онлайн-бот для ежедневной и многократной публикации текстов в Telegram. Расписание, тема, инструкция, AI-провайдер и список чатов хранятся в `config.json`. Секреты не записываются в репозиторий.

## Как это работает

GitHub Actions запускает проверку каждые пять минут. Скрипт читает локальное время из `config.json`, сравнивает его со списком `schedules`, при совпадении генерирует новый текст и отправляет его в каждый `chat_id`. В ручном запуске workflow можно передать `send_now=true`, чтобы отправить сообщение сразу, независимо от расписания.

GitHub Actions может запускаться с задержкой относительно cron, поэтому это подходит для ежедневных публикаций с допуском в несколько минут, но не для секундной точности.

## Секреты GitHub

В репозитории открой `Settings → Secrets and variables → Actions → New repository secret` и добавь нужные секреты:

| Secret | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от BotFather |
| `GROQ_API_KEY` | Ключ Groq, если выбран `groq` |
| `GEMINI_API_KEY` | Ключ Gemini, если выбран `gemini` |
| `OPENAI_API_KEY` | Ключ OpenAI, если выбран `openai` |

Для публикации в `@coding_222573g` бот должен быть администратором канала с правом публикации.

## Настройка `config.json`

Пример нескольких запусков в день:

```json
{
  "enabled": true,
  "timezone": "Asia/Almaty",
  "schedules": [
    { "time": "09:00", "days": ["mon", "tue", "wed", "thu", "fri", "sat", "sun"] },
    { "time": "14:30", "days": ["mon", "wed", "fri"] },
    { "time": "20:00", "days": ["sat", "sun"] }
  ],
  "chat_ids": ["@coding_222573g"],
  "topic": "Новости программирования",
  "instruction": "Напиши новый текст. Не повторяй последние сообщения.",
  "language": "русский",
  "max_length": 700,
  "provider": "groq",
  "model": "openai/gpt-oss-120b"
}
```

Android-приложение уже умеет менять этот файл через GitHub Contents API. В приложении укажи `owner/name` репозитория и GitHub fine-grained token с доступом только к этому репозиторию: `Contents: Read and write` и `Actions: Read and write`. Кнопка «Передать настройки онлайн» обновляет `config.json`, кнопка «Включить отправку по времени» передаёт `enabled=true`, кнопка «Выключить» передаёт `enabled=false`, а «Отправить сейчас онлайн» запускает workflow с `send_now=true`. Для нескольких запусков укажи времена через запятую, например `09:00, 14:30, 20:00`. Токен хранится локально на телефоне и не должен публиковаться в репозитории или отправляться в чат.

## Проверка

Для ручной проверки открой вкладку `Actions`, выбери `Telegram scheduled bot`, нажми `Run workflow` и установи `send_now=true`. После выполнения проверь сам канал и файл `history.json`.
